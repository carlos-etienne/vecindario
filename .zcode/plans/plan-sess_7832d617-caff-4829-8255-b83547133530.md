## Gestión del sitio vía Telegram con Hermes Agent

### Decisión: Hermes Agent (DeepSeek Harness no es competidor para esto)

- **Hermes Agent** (NousResearch, open source) es exactamente el patrón que platicamos: un bot conversacional en Telegram, corriendo 24/7, que puede operar archivos y el repo del sitio. Es "el mayordomo al que le escribes desde el bar".
- **DeepSeek Harness** es un agente de **programación** con interfaz de navegador (sesiones de trabajo tipo IDE). No es un bot de Telegram ni un mayordomo — resolvería otra necesidad (desarrollo asistido con UI web), no la gestión diaria.
- **Matiz útil**: si te gusta el ecosistema DeepSeek, su lugar natural aquí es como **modelo detrás de Hermes** (vía API), no el Harness como producto aparte.
- El VPS de Hostinger será el host de Hermes (hay guías de despliegue oficiales; plantilla Docker).

### Arquitectura: estática + rebuild automático (D1 queda para después)

```
Telegram → Hermes (VPS) edita web/src/data/taps.json
        → commit + push a GitHub (privado)
        → Cloudflare Pages rebuild (~1 min)
        → sitio actualizado
```

- El sitio sigue **100% estático**: velocidad del QR en mesas intacta, cero backend que mantener.
- El historial de git es la red de seguridad: "revierte el último cambio" siempre funciona.
- D1 solo entraría en el futuro si necesitaras algo en tiempo real (la rotación de taps es 1-2 veces por semana; el rebuild de 1 minuto es irrelevante).

### F0 — Base de publicación (prerrequisito, ya estaba pendiente)

1. `git init` del proyecto + `.gitignore` (node_modules, dist, .astro) + repo **privado** en GitHub + primer push.
2. Cloudflare Pages conectado al repo: root `web/`, build `npm run build`, output `dist/`.
3. Conectar el dominio vecindariobeergarden.com cuando el sitio esté aprobado (momento delicado de migración SEO desde el WP actual).

### F1 — VPS + Hermes Agent

4. Contratar VPS Hostinger (plan KVM básico, 1-2 vCPU / 2-4 GB — sobra para Hermes).
5. Instalar Hermes en Docker; crear el bot con BotFather; allowlist de Telegram: tú (+ tu socio si quieres).
6. Acceso al repo con **token fine-grained de GitHub**: solo este repo, solo escritura — mínimo privilegio.
7. Escribir el manual del agente (`SKILL.md` en el repo): schema de `taps.json`, validaciones (10 taps, precios numéricos, ABV/IBU, disponible), y las reglas de copy honesto que ya documentamos (se reutiliza el skill existente).
8. Prueba end-to-end: cambiar una tap desde Telegram → push → deploy → verificar el sitio → revertir.

### F2 — Reglas de publicación (según lo acordado)

9. **Cervezas/precios → publicación directa** (push a main solo para `taps.json`).
   **Textos/diseño/otras páginas → con aprobación**: el agente abre un PR, Cloudflare genera un link de vista previa, y se publica al aceptarlo (un clic, desde el link que el bot te manda en Telegram).
10. (Opcional) aviso automático en Telegram cuando el deploy termina.

### Costos (referencia)

- Cloudflare Pages: **gratis** para este tráfico · GitHub privado: **gratis** · VPS KVM: ~US$5-10/mes (único costo fijo) · Modelo LLM detrás de Hermes: variable, bajo para uso esporádico (DeepSeek API es de las más económicas si vamos por esa ruta).

### Verificación final

- Cambio real de tap probado end-to-end con medición de tiempo (mensaje → sitio vivo).
- Prueba de rollback (revertir).
- Confirmar que un cambio de texto NO se publica sin tu aprobación.
